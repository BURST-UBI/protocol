# Verification record normalization implementation contract

Status: implemented and active during production startup after recovery, before admission.
Codecs, scoped writers, historical-journal compatibility, bounded fallback, planner,
process-crash and startup checks pass. Certified1,024-pool and completed1,024-panel node
persistence now pass, closing the demonstrated row-size blocker. Cold/global/resource
and broader lifecycle qualification remain in the operation audit. This document's
historical sections record earlier incomplete states; the current ledger is authoritative.

## Proven problem

A certified two-member committee from1024 eligible, valid addresses installs and
roundtrips its snapshot (76227 bytes), but its target row fails the64KiB local codec.
The128-pool control succeeds (10819 snapshot bytes). Separately, a1024-member synthetic
panel initially fits its target row but its completed deadline does not. Thus the
problem is both immutable pool duplication and growing vote/history payloads; it is
not confined to choosing a huge committee. These are codec diagnostics, not successful
node persistence scenarios. The selection fixture uses its existing checkpoint
signature and beacon validation; no authority checks were bypassed.

## Representation requirements

Keep each physical row within64KiB and keys within511 bytes. Retain the64MiB snapshot/
undo budgets and65536 journal change bound. Keep signed block/checkpoint encodings,
selection commitments, governed committee counts, economic outcomes and peer framing.

Normalize the logical target by semantic identity, not fixed byte offsets in its
serialized aggregate. Byte pages alone would shift after a vote insertion and retain
whole-target serialization. Separate bounded target/selection scalar headers from:

- Endorsements and endorser membership, keyed by endorser identity.
- Selected committee members and immutable selection pool, preserving their validated
  order. Write the pool when a selection changes; ordinary votes must not rewrite it.
- Current votes and prior-round votes, keyed by voter in separate domains. Valid
  settlement forbids duplicate voters across rounds; preserve the existing canonical
  snapshot order and reject duplicates rather than silently coalescing them.
- Excluded identities and attempt vote bindings, keyed by identity.
- Existing verifier penalty/history records, with their current validation rules.

Headers must retain absent-versus-present-empty domains and exact member counts.
Readers reject missing headers, missing/extra members, duplicate keys, mixed old/new
representations and mismatched identities. Reader memory and snapshot accounting must
include all reconstructed state before publication. Small challenge/appeal fields
stay available to the existing point-read consumer without loading the entire pool.

Scoped writes must compare changed members and leave unrelated pool/history bytes
untouched. Merely emitting small rows after cloning/serializing the whole target is
an intermediate codec fix, not completion of the complexity requirement. Trace mutable
state tracking and immutable baselines as part of the same implementation.

## Larger-history migration direction — 2026-10-21

physical changes and requires retaining a cumulative history buffer in the current
migration. Preserve original journal bytes instead, with target-specific virtual undo

must not treat a successful point codec as history authentication or discard malformed
