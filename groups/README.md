# Off-chain groups

`burst-groups` provides directory validation, live membership queries and bounded
trust-path searches. Group judgments are wallet policy inputs, not consensus votes.

See the [group service guide](../docs/node/GROUP_SERVICES.md) for directory JSON,
export commands, membership and trust APIs, limits and privacy behavior.
See [wallet trust policies](../docs/wallet/WALLETS.md#group-trust) for payment decisions.
